1. 語彙練習 選択問題

1. Choose the correct reading: (world)

2. 助詞・活用練習

1. 毎週、日本語のクラス（　）行きます。

2. 部屋（　）掃除します。

3. 映画は七時に（始まる → 丁寧形）。

4. よく（考える → て形）から、答えを書いてください。

5. 窓を（開ける → 過去の丁寧形）。

3. 読解問題

たけしさんは毎週土曜日に日本語を勉強します。勉強は午前十時に始まります。たけしさんは図書館の部屋で友達と勉強します。分からない漢字があると、辞書で調べて、意味をよく考えます。勉強が終わった後、友達と運動します。

※ この短い文章は、教材の語彙を使って作った練習用の文章です。

1. たけしさんはいつ日本語を勉強しますか。

2. 勉強は何時に始まりますか。

3. 分からない漢字があると、たけしさんは何をしますか。

4. 記述問題

日本語で答えてください。入力後、「確認」を押すと、回答例を見られます。

1. 毎週、何をしますか。（一文で書きましょう）

回答例：毎週、日本語を勉強します。
自分の生活に合わせて書いてもいいです。

2. 最近、何について考えましたか。

回答例：来週の予定について考えました。

3. 好きな部屋・場所について、二文で説明してください。


回答例：私の好きな場所は図書館です。静かな部屋で本を読むことができます。

5. ○×問題（読解内容の確認）

文章をもう一度読んで、内容が正しければ○、違っていれば×を選んでください。

1. たけしさんは毎週土曜日に日本語を勉強します。

2. たけしさんの勉強は午後十時に始まります。

3. たけしさんは図書館の部屋で友達と勉強します。

4. 分からない漢字があると、たけしさんは辞書を使わずに、すぐ運動します。

5. 勉強が終わった後、たけしさんは友達と運動します。

6. 確認テスト

最後のミニテストです。全部答えたら得点を確認しましょう。

1. 「全国」の読み方は？

2. 「教室」の意味は？

3. 「運動する」の意味は？

4. 「部長」はどんな人ですか。

5. 日本語の勉強は来週（　）始まります。

答え一覧
語彙：1. せかい（world）　2. まいしゅう　3. かんがえる　4. へや
助詞・活用：1. に　2. を　3. 始まります　4. 考えて　5. 開けました
読解：1. 毎週土曜日　2. 午前十時　3. 辞書で調べて、意味を考える
○×（読解）：1. ○　2. ×　3. ○　4. ×　5. ○
確認テスト：1. ぜんこく　2. classroom　3. to exercise　4. 部・部署の長　5. に
